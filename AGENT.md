# AGENT.md

## Project Summary

Scout is a premium, social sports app built around local player discovery, pickup matchmaking, inner circles, asynchronous brackets, rankings, and local business discovery.

This website exists to market the product, make the value instantly clear, drive early signups, explain pricing, and establish a scalable foundation for future business and club partnership content.

The product and website should feel dark, premium, sporty, bold, modern, slightly exclusive, and community-driven. The site should feel like an extension of the app, not a generic startup landing page.

## Design Rules

- Always use purple and blue accents, never green or lime
- Keep the overall theme dark, premium, and high contrast
- Prefer large rounded cards and roomy layouts over cramped grids
- Use bold headlines and strong visual hierarchy
- Preserve sports, social, and product energy throughout the site
- Avoid generic SaaS styling, bland enterprise sections, and flat layouts

## Build Rules

- Use React + TypeScript + Vite
- Use Tailwind CSS for styling
- Prefer reusable components and shared sections
- Keep code modular and easy to extend
- Structure pages so they can grow into a full marketing site
- Maintain responsive behavior across mobile, tablet, and desktop
- Keep components readable, focused, and well organized

## UX Rules

- Prioritize immediate clarity about what Scout is and why it matters
- Every page should include a clear CTA
- Visuals should make the product feel active, local, and socially alive
- Pricing should be easy to scan and easy to compare
- Motion should feel subtle, premium, and supportive, never distracting

## Content Rules

- Tone should feel confident, modern, social, and premium
- Avoid overly corporate copy
- Avoid generic AI-sounding filler text
- Keep copy direct, conversion-oriented, and product-specific

## Engineering Rules

- Keep styling tokens consistent across pages
- Centralize constants and shared content where useful
- Use semantic naming for components and data structures
- Avoid giant monolithic files
- Build sections as composable units that can be rearranged later

## Done Criteria

- Responsive home page
- Responsive pricing page
- Responsive how-it-works page
- Responsive business/clubs page
- Shared nav and footer
- Visual consistency across all pages
- Clean build with no obvious placeholder junk
